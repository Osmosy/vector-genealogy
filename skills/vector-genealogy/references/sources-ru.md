## Как этим пользоваться

1. Начинать с того, что точно индексировано: Яндекс Архивы по метрикам, ОБД «Мемориал» по потерям,
   «Подвиг народа» по наградам, «Открытый список» по репрессиям.
2. Память народа — только браузером; если антибот не пускает, те же данные берутся из ОБД и
   «Подвига народа» по отдельности.
3. gwar.mil.ru — либо браузер с принятым исключением для сертификата Минцифры, либо установка
   корневого сертификата УЦ Минцифры (в навыке лежат `scripts/ca/russian_trusted_root_ca.pem` и
   `russian_trusted_sub_ca.pem`). Проверять, что сертификат действительно от Минцифры, а не подмена.
4. Старые сайты (`forum.vgd.ru`, `svrt.ru`, `statearchive.ru`) отдают windows-1251 — читать
   с определением кодировки, иначе вместо текста будет мусор.
5. Любая находка идёт в реестр как артефакт с URL, датой и цитатой; выводы делаются из реестра,
   а не из памяти о том, что «где-то видел».

## Что здесь не проверялось

Доступность с других сетей и из других стран, работа под VPN, поведение этих сайтов при
массовых запросах, оплата и лимиты платных разделов (Яндекс Архивы, Familio, FamilySearch).
Дата проверки указана выше — перед длинным исследованием повторить замер, сайты меняются.
