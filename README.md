# Vector Genealogy

Навык для агента: восстановление семейной истории по публичным архивам бывшего СССР —
метрические книги, ревизские сказки, воинский учёт, репрессии, депортации, эмиграция.
Работа идёт как дело: вопрос → план → артефакты → утверждения → проверка → отчёт.
Каждое звено родства опирается на запись с происхождением, а не на совпадение фамилии.

## Установка

```bash
git clone https://github.com/Osmosy/vector-genealogy
cp -r vector-genealogy/skills/vector-genealogy ~/.hermes/skills/
```

Дальше агент находит навык по описанию; вручную — `skill_view(name='vector-genealogy')`.

## Как пользоваться

Ставится задача, подключается навык, агент ведёт дело в отдельном каталоге:

```bash
python3 scripts/init_case.py --case-dir ~/род --research-question "Кем был прадед до 1917 года?"
python3 scripts/audit_evidence.py --case-dir ~/род
```

Скрипты только пишут файлы дела и проверяют реестры; ничего сами не ищут. Поиск ведёт агент
доступными ему средствами — браузер, веб-поиск, скачивание сканов.

## Источники: что реально работает

Проверено 01.11.2026 с домашней сети в России, без VPN: `curl` с браузерным User-Agent и живой
Chromium. Подробности и оговорки — `references/sources-ru.md`.

- работают: `podvignaroda.ru`, `obd-memorial.ru`, `ru.openlist.wiki`, `bessmertnybarak.com`,
  `yandex.ru/archive`, `familio.org`, `familysearch.org`, `forum.vgd.ru`, `svrt.ru`,
  `online.archives.ru`, `archives.gov.ru`, `statearchive.ru`, `george-orden.narod.ru`;
- требуют браузера: `pamyat-naroda.ru` (антибот «Проверка безопасности»);
- требуют доверенного сертификата Минцифры: `gwar.mil.ru` (иначе Chromium выдаёт ошибку
  конфиденциальности); в навыке лежат `scripts/ca/russian_trusted_root_ca.pem` и подчинённый;
- не отвечал: `rgada.info` (отказ соединения).

Вывод, который стоит держать в голове: половина ценных баз не отдаётся простому HTTP-клиенту.
Начинать с браузера, а не с `curl`, иначе покажется, что архив «закрыт».

## Проверка

```bash
python3 -m unittest discover -s tests -q     # Ran 84 tests ... OK
```

Тесты — из апстрима, проверяют разбор поисковой выдачи, реестры, аудит доказательств,
сборку лент сканов и шаблон запроса в архив. На этой машине проходят на Python 3.14.4.

## Чем это не является

- Не `vector-gene`: там персональная геномика (интерпретация ДНК), здесь — архивный поиск и
  доказательства родства по документам. Разные задачи, разные навыки.
- Не поисковик по базам: навык задаёт процедуру и проверки, а ищет агент инструментами.
- Не обещание результата: ночь работы даёт гипотезы и план; доказанная цепочка — это месяцы
  и переписка с архивами.
